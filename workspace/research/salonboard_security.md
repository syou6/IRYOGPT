# Research: salonboard.com Security and Anti-Bot Measures

Date: 2026-03-29

---

## Executive Summary

salonboard.com is protected by **Akamai Bot Manager** as its primary anti-bot layer, delivered through Akamai's CDN/WAF infrastructure. The login endpoint (`/CNC/login/doLogin/`) uses Java session management (JSESSIONID) with no visible CSRF token in the form. The site has no public API — third-party integrations rely entirely on scraping. Real-world reports confirm that aggressive scraping triggers **image CAPTCHA challenges** (not reCAPTCHA, but a custom/generic image auth). No known public GitHub scraping projects specifically target salonboard.com. The obfuscated bot-detection JavaScript (`/sOKJO3/la0/LbV/...`) is Akamai's sensor data collector, served on every page including the login page.

## 2. Akamai Bot Manager

### Confirmed Bot Manager Cookies (set on every page load, including login)

| Cookie Name | Domain | Expires | Notes |
|---|---|---|---|
| `_abck` | `.salonboard.com` | 1 year | Primary Akamai Bot Manager detection token |
| `bm_sz` | `.salonboard.com` | ~4 hours | Akamai session/telemetry token |
| `GalileoCookie` | `salonboard.com` | 10 years | Akamai sticky-session / load-balancing cookie |

**`_abck` (primary anti-bot token):**
- Generated by the obfuscated JavaScript sensor script
- Contains encrypted browser telemetry (fingerprint + behavioral data)
- Validated on subsequent requests; invalid = blocked/challenged
- Initial value has `-1~-1~-1~-1~-1` sequence indicating unvalidated state — the JS must POST sensor data back to Akamai to "validate" it

**`bm_sz` (session tracker):**
- Short-lived (~4 hours), rotates per session
- Used to distinguish bots from humans at request level

**`GalileoCookie`:**
- Long-lived (10-year expiry) suggesting it is a persistent identifier
- Likely Akamai's sticky session cookie for routing to same edge server

### The Obfuscated Bot Detection Script

Every page on salonboard.com (including `/login/`) injects:
```html
<script type="text/javascript" src="/sOKJO3/la0/LbV/YWdV4A/iE3iXcrVJpGwQV/QSkuAwE/KSs_O/Fo3KDQB"></script>
```
This is **Akamai Bot Manager's sensor collection JavaScript** — heavily obfuscated (~527KB). It:
- Collects device fingerprint (screen resolution, fonts, plugins, hardware)
- Tracks behavioral signals (mouse movement, click timing, typing patterns)
- Detects automation indicators (Selenium/Playwright `navigator.webdriver`, missing browser APIs, non-human timing patterns)
- POSTs sensor data back to Akamai's edge
- Validates and "stamps" the `_abck` cookie on success

### Akamai Detection Layers
1. **TLS fingerprinting** — Python's `requests`/`httpx` and even Scrapy have known bot TLS fingerprints (cipher suites, ALPN). Akamai blocks these at the TLS handshake level.
2. **JavaScript sensor data** — The obfuscated script collects 40+ browser/device properties
3. **Behavioral analysis** — Mouse movement, scroll, click timing entropy
4. **IP reputation** — Data center IPs, VPN ranges, known scraping infrastructure
5. **Request pattern analysis** — Too-fast page loads, missing referrer, suspicious navigation order

## 3. Login Page Security

### Login Form Details
- **URL**: `https://salonboard.com/login/`
- **Form action**: `/CNC/login/doLogin/` (POST)
- **Form fields**:
  - `userId` (text input, IME disabled)
  - `password` (password input, ID: `jsiPwInput`)
  - `idCheckFlg` (checkbox, value=1, "remember ID")
  - `spFlg` (hidden field for mobile/desktop flag)
- **No visible CSRF token** in the form HTML

### Session Cookie
```
JSESSIONID=xxx.ap452_0B1; Path=/CNC; Secure; HttpOnly
```
- Java-based application (`.ap452_0B1` suffix indicates server node identifier for sticky sessions)
- `Secure` + `HttpOnly` flags set — not accessible via JavaScript
- Scoped to `/CNC` path only
- The server node suffix (`.ap452_0B1`) combined with `GalileoCookie` ensures session affinity

### Security Headers on Login Page
```
X-Frame-Options: SAMEORIGIN
Cache-Control: no-store
Pragma: no-cache
Expires: Thu, 01 Dec 1994 16:00:00 GMT (forced expiry)
P3P: CP="NON DSP COR CURa ADMa DEVa TAIa PSDo OUR BUS UNI COM NAV STA"
```
- No `Content-Security-Policy` header observed
- No `Strict-Transport-Security` (HSTS) header observed in responses
- `X-Frame-Options: SAMEORIGIN` prevents clickjacking

### Login Endpoint
```
POST /CNC/login/doLogin/
POST /CNC/idPasswordInput/
POST /CNC/mgr/loginGuide/
```
The JS in the login page uses `$submit()` with a 3-second double-submit lock, indicating basic client-side submission throttling.

SalonConnect's FAQ explicitly mentions "画像認証" (image authentication) appearing on salonboard — this is an image-based CAPTCHA (not Google reCAPTCHA) that Akamai Bot Manager can trigger during login or navigation when bot signals accumulate.

- No documented specific thresholds publicly available
- CrowdWorks job post implies scraping speed must be throttled ("scraping speed" is a parameter)
- SalonConnect experiences intermittent CAPTCHA triggers despite professional tuning
- The `bm_sz` cookie expires every ~4 hours, requiring periodic re-validation

### Account Lockout
No specific lockout policy found in public documentation. Standard behavior for Java web apps with Akamai protection: repeated failed logins or rapid automated requests trigger CAPTCHA challenges before hard lockout.

## 8. Automation Detection — Specific Behaviors

Based on Akamai Bot Manager's known detection methods as they apply to salonboard:

1. **Missing `_abck` validation**: Any request that skips JavaScript execution will have an unvalidated `_abck` (contains `-1~-1~-1~-1~-1`). Akamai detects this and may silently flag or block.

2. **TLS fingerprint mismatch**: Python `requests`, `httpx`, `aiohttp`, Scrapy all have known bot-classified TLS fingerprints. They will be detected at the network layer before any cookie or JS logic runs.

3. **`navigator.webdriver = true`**: Default Selenium/Playwright detection. The Akamai JS specifically checks for this and other headless browser artifacts.

4. **Browser API anomalies**: The sensor script (~527KB) checks for missing browser globals, non-standard API implementations, and other headless signatures.

5. **Behavioral timing**: Mouse events, click patterns, and keystroke timing outside human norms trigger behavioral flags.

6. **IP reputation**: Akamai maintains IP reputation databases. Data center IPs (AWS, GCP, etc.) are flagged by default.

7. **Request sequencing**: Accessing the login POST endpoint without proper prior GET requests, without referrer headers, or without the JSESSIONID from the initial login page load will fail or trigger challenges.
